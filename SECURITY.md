# Security Policy

## Reporting a Vulnerability

If you believe you have found a security vulnerability in Mashhad, please report it privately.

- Email: knight007youtu@gmail.com

Please include as much detail as possible:

- A clear description of the issue and impact
- Steps to reproduce (proof-of-concept code is welcome)
- Affected URLs / routes / components (if known)
- Any logs or screenshots that help explain the issue

We will acknowledge receipt, investigate, and coordinate a fix. Please do not disclose the issue publicly until we confirm a fix is available.

## Supported Versions

Security fixes are applied to the `main` branch. There is currently no long-term support (LTS) branch.

## Scope Notes

Mashhad integrates with third-party providers (e.g., Clerk, Supabase, Stripe, TMDB, Real-Debrid, subtitle providers). Reports covering misconfiguration, token exposure, SSRF, auth bypass, or unsafe proxying are in scope.
